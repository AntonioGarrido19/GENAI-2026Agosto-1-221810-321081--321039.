# Asistente inteligente para la gestión de restaurantes

## Descripción

Este proyecto propone un asistente basado en modelos de lenguaje (LLM) para ayudar al administrador de un restaurante a consultar información del negocio, analizar y comparar sus productos. La solución combinará datos internos del restaurante con herramientas de análisis y búsqueda web, y podrá presentar los resultados en lenguaje natural y mediante gráficas.

El asistente busca facilitar consultas que normalmente requieren revisar varias fuentes o preparar informes manualmente. Las respuestas deberán indicar de dónde provienen los datos y cuándo una conclusión sea una estimación, una comparación parcial o no pueda verificarse.
